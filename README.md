# new

A Django project powered by [labb](https://labb.io) - the perfect Django UI components library.

## Getting Started

This project was created with `labbstart` and includes the `web` starter app with a beautiful welcome page.

### Development

You need to run two processes in separate terminals:

**Terminal 1 - CSS Development Server:**
```bash
source venv/bin/activate && labb dev
```

**Terminal 2 - Django Development Server:**
```bash
source venv/bin/activate && python manage.py runserver
```

Then visit `http://localhost:8000` to see your project!

### Project Structure

- `new/` - Django project settings
- `web/` - Your starter app with labb components
- `static/` - CSS output (generated by labb build)
- `static_src/` - CSS source files (Tailwind CSS)

### Welcome Page

The welcome page includes:
- 🎨 Theme switcher (light/dark/system)
- ✨ Beautiful gradient background with animated blob
- 📝 Quick start guide
- 🔗 Links to documentation and GitHub

### Available Commands

#### labb Commands

```bash
# Build CSS (one-time)
source venv/bin/activate && labb build

# Development mode (watch and rebuild CSS)
source venv/bin/activate && labb dev

# View configuration
source venv/bin/activate && labb config

# Explore components
source venv/bin/activate && labb components ex --tree

# Get component info
source venv/bin/activate && labb components inspect <component>
```

#### Django Commands

```bash
# Run development server
source venv/bin/activate && python manage.py runserver

# Create migrations
source venv/bin/activate && python manage.py makemigrations

# Apply migrations
source venv/bin/activate && python manage.py migrate

# Create superuser
source venv/bin/activate && python manage.py createsuperuser
```

## Customization

### Edit the Welcome Page

The welcome page template is located at:
```
web/templates/pages/index.html
```

### Customize Your Theme

Edit your theme in:
```
static_src/input.css
```

The welcome kit includes custom CSS in:
```
static_src/web.css
```

### Add Components

Explore available components:
```bash
source venv/bin/activate && labb components ex --tree
```
